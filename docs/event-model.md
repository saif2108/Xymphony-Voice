# Event Model

**Status:** Phase 0 contract. Implementation lives later in `packages/contracts` (Python) and generated TypeScript.  
**Runtime behavior:** [runtime-design.md](runtime-design.md)

Events are the **internal lingua franca** of the data plane and the **public inspector** model (filtered). They are not hidden chain-of-thought.

---

## 1. Why events

| Problem | Event model |
| --- | --- |
| Barge-in races | Sequence + turn_id + ignore rules |
| Live Agent Brain | Project structured events to UI |
| Traces | Map events to OTel spans |
| Multi-modal later | New payload types, same envelope |
| Multi-agent later | `source` + `agent_id` + `correlation_id` |

---

## 2. Envelope (normative)

```
Event {
  id               UUID          # unique, client-generated by producer
  type             string        # see catalog
  timestamp        datetime      # UTC, producer clock
  session_id       UUID
  organization_id  UUID          # tenancy
  project_id       UUID
  agent_id         UUID          # identity
  agent_version_id UUID
  deployment_id    UUID | null   # null in playground
  turn_id          UUID | null
  sequence         int           # monotonic per session, starts at 1
  source           string        # vad|stt|runtime|llm|tts|tool|workflow|transport|system
  correlation_id   UUID          # usually session_id or request id
  causation_id     UUID | null   # id of event that caused this one
  payload          object        # type-specific
  metadata         object        # non-authoritative extras
  schema_version   int           # envelope version, currently 1
  trace            { trace_id, span_id } | null
}
```

| Field | Why |
| --- | --- |
| `id` | Idempotency of persist/UI |
| `type` | Dispatch |
| `timestamp` | Display; **ordering uses sequence**, not timestamp |
| `session_id` | Isolation |
| `organization_id` / `project_id` | Tenant filters; never infer from agent only |
| `agent_id` / `agent_version_id` | What actually ran |
| `deployment_id` | Prod vs playground |
| `turn_id` | Cancellation scope |
| `sequence` | Total order in a session |
| `source` | Debugging |
| `correlation_id` | Cross-service logs |
| `causation_id` | Causal chain (e.g. TTSChunk caused by LLMToken batch) |
| `payload` | Body |
| `metadata` | Latency hints, provider name, usage |
| `schema_version` | Additive evolution |
| `trace` | OTel join |

**Ordering:** The loop **assigns** `sequence` when the event is **admitted**, not when the network packet arrived. Out-of-order STT packets are buffered or dropped per STT adapter; they do not reorder the session sequence.

**Clock skew:** `timestamp` is informational. Do not sort inspector by timestamp alone.

## 3. Persistence policy

| Class | Persist | Example |
| --- | --- | --- |
| Ephemeral | No (P1) | `AudioFrame`, partial `LLMToken` (or sample 1%) |
| Durable | Yes | finals, tools, interrupts, errors, workflow transitions |
| Dual | In-memory bus + async persist | `TranscriptFrame` final, `AgentInterrupted` |

UI live view: Redis pub/sub of a **safe subset** (no audio PCM).

Idempotent persist: unique `(session_id, id)` or `(session_id, sequence)`.

---

## 4. Cancellation and retries

- Cancel does **not** delete events already admitted.  
- Cancel emits `AgentInterrupted` and future stale payloads are **not admitted**.  
- Retries: new event with new `id`, `causation_id` = failed event, `metadata.retry_of`.  
- Consumers (UI, persist) are idempotent on `id`.

## 5. Type catalog

Types are **conceptual contracts**. P1 implements a subset.

### 5.1 Media and speech

| Type | Payload (conceptual) | P1 |
| --- | --- | --- |
| `AudioFrame` | `{track, codec, data_ref or bytes, duration_ms}` | In-memory only |
| `TextFrame` | `{text, role}` | NEAR text channel |
| `UserSpeechStarted` | `{vad_confidence?}` | Yes |
| `UserSpeechEnded` | `{duration_ms}` | Yes |
| `TranscriptFrame` | `{text, is_final, start_ms, end_ms, confidence?}` | Yes |
| `AgentInterrupted` | `{interrupted_turn_id, reason, played_text, unplayed_text}` | Yes |

### 5.2 Model and tools

| Type | Payload | P1 |
| --- | --- | --- |
| `LLMToken` | `{delta}` | Optional persist |
| `LLMResponse` | `{text, finish_reason, usage}` | Yes (final) |
| `ToolCall` | `{tool_call_id, name, arguments}` | NEAR |
| `ToolResult` | `{tool_call_id, ok, data, error}` | NEAR |
| `TTSChunk` | `{audio_ref, text_range}` | No persist |

### 5.3 Workflow, agents, errors

| Type | Payload | Horizon |
| --- | --- | --- |
| `WorkflowTransition` | `{from_node, to_node, reason}` | LATER |
| `AgentTransferred` | `{from_agent_id, to_agent_id, summary_ref}` | LATER |
| `HumanTakeover` | `{operator_id}` | LATER |
| `RetrievalResult` | `{query, chunk_ids, scores}` | NEAR |
| `Error` | `{code, message, retryable}` | Yes |
| `SessionStarted` / `SessionEnded` | `{reason}` | Yes |

## 6. Examples

**User speech start (interrupt):**

```json
{
  "id": "7c2e…",
  "type": "UserSpeechStarted",
  "timestamp": "2026-09-07T12:00:01.200Z",
  "session_id": "s1",
  "organization_id": "o1",
  "project_id": "p1",
  "agent_id": "a1",
  "agent_version_id": "v12",
  "deployment_id": null,
  "turn_id": "tu-9",
  "sequence": 104,
  "source": "vad",
  "correlation_id": "s1",
  "causation_id": null,
  "payload": {},
  "metadata": {},
  "schema_version": 1,
  "trace": {"trace_id": "…", "span_id": "…"}
}
```

**Tool result (NEAR):**

```json
{
  "type": "ToolResult",
  "turn_id": "ta-8",
  "sequence": 88,
  "source": "tool",
  "causation_id": "<toolcall-event-id>",
  "payload": {
    "tool_call_id": "c1",
    "ok": true,
    "data": {"eligible": true}
  }
}
```

The LLM may then say “the claim is eligible” **only because** `eligible` came from the tool.

## 7. Versioning

- Envelope `schema_version`: increment on breaking field rename.  
- Additive optional fields: no increment required; consumers ignore unknown keys.  
- `type` strings are stable; never reuse a type for a different payload.  
- Persist original `schema_version` for replay.

---

## 8. Future modalities and A2A

Same envelope. New types: `ImageFrame`, `FilePart`, `VideoFrame`, `AgentMessage`. Multi-agent: `source=agent:{id}` and `AgentTransferred`. Do not create a second parallel event system for text vs voice.

---

## 9. What is not an event

- Hidden CoT  
- Raw provider billing webhooks (those are ops)  
- Control-plane CRUD audit (that is `audit_logs`, not session events)

---

## 10. Tests

- Sequence monotonic  
- Duplicate `id` ignored  
- After `UserSpeechStarted`, no `TTSChunk` for previous `turn_id` admitted  
- `Error` always admitted even during cancel
