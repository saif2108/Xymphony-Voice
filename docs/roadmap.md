# Roadmap

Times are **planning assumptions** for two engineers with heavy AI assistance — **not guarantees**.

| Horizon | Clock (approx) | Outcome |
| --- | --- | --- |
| **Current** | 2026-09-07 | Empty repo + Phase 0 docs |
| **Phase 0** | this documentation | Architecture frozen enough to implement |
| **Prototype 1** | 7–14 working days | Create agent, talk, barge-in. [prototype-1.md](prototype-1.md) |
| **Prototype 2** | +3–5 weeks | RAG, tools/MCP, inspector, more adapters, basic analytics |
| **Beta** | +6–10 weeks after P2 | Memory v1, versioning publish, workflows start, eval, HITL, OTel maturity |
| **V1** | ~4–6 months from start | Serious product: deploy channels, SDK, RBAC, routing, simulation |
| **Vision** | ~9–15 months | World-class platform slice |
| **Enterprise ecosystem** | ~15–24+ months | Governance, telephony, marketplace, on-prem |

Assumptions: both engineers full-time; vendors stable; no major LiveKit/protocol rewrite; scope discipline on P1.
